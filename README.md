# YouTube Clone

This is a YouTube-like web application built with React.

## Features

- Video search (by title, channel, description)
- Category filtering
- Shorts page
- Video player page
- Profile dropdown and profile page
- Global error handling page
- Responsive sidebar and layout

## Technologies

- React
- React Router DOM
- CSS
- Vite

## Project Structure

- **Navbar** – navigation and search functionality
- **Sidebar** – categories and navigation
- **Home** – video feed
- **Video** – video player page
- **Shorts** – short video content
- **Profile** – user profile page
- **SearchResults** – search results page
- **ErrorPage** – global error handling

## Run the project

```bash
npm install
npm run dev
```
